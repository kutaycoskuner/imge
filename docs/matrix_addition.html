II. description

Matrix addition

Two matrices of the same size are added entry by entry: each entry of C is the sum of the entries at the same place in A and B.

crc=arc+brcc_{rc} = a_{rc} + b_{rc}crc​=arc​+brc​

Size rule

A and B must have the same size: i=mi = mi=m and j=nj = nj=n.

i=2=m=2,j=3=n=3i = 2 = m = 2, \quad j = 3 = n = 3i=2=m=2,j=3=n=3 ✓ The sizes match.

C has the same size as A and B: i×ji \times ji×j. Here: 2×3.

Properties

Order does not matter: A+B=B+AA + B = B + AA+B=B+A (commutative), and (A+B)+C=A+(B+C)(A + B) + C = A + (B + C)(A+B)+C=A+(B+C) (associative).

The zero matrix changes nothing: A+0=AA + 0 = AA+0=A.
